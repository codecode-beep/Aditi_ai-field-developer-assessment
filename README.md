# AI Field Developer Assessment

This repository contains my solutions to four practical AI Field Developer assessment tasks. The projects cover MCP servers and gateways, streaming PII redaction, and LLM request routing.

## Tasks

1. [Custom MCP Server](task_1_mcp_server/README.md) — Customer tools with input validation and stdio transport.
2. [MCP Security Gateway](task_2_mcp_gateway/README.md) — HTTP/JSON-RPC proxy with role-based tool authorization.
3. [Streaming PII Guardrail](task_3_llm_stream_guardrail/README.md) — Streaming response proxy that redacts sensitive information.
4. [Rate Limiting and Model Fallback](task_4_rate_limit_fallback/README.md) — Token-aware tenant limits, SQLite storage, and backup-provider routing.

Each task folder contains its own setup instructions, dependencies, and run steps.
